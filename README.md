# hello-popup

A tiny Python script that pops up a message box saying "hello" when run.

## Run

```bash
python hello.py
```

Requires Python 3 with tkinter — bundled with the standard installers on
Windows and macOS. On Debian/Ubuntu Linux: `sudo apt install python3-tk`.
